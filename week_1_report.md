# Week 1 Internship Report

## Project Title
Personal Portfolio Website

## 1. Introduction
This project is a simple personal portfolio website developed as part of Week 1 of my Frontend Web Development internship. The website provides information about a person, their skills, projects, and contact details.

## 2. Objective
The main objective of this project is to understand the basics of HTML and CSS and learn how to convert a basic wireframe into a static web page.

## 3. Technologies Used
- HTML5
- CSS3
- Visual Studio Code
- Web Browser

## 4. Project Description
The Personal Portfolio Website contains different sections such as Home, About, Skills, Projects, and Contact. These sections are designed to present personal information in a simple and organized way.

## 5. Implementation Details
HTML was used to create the structure of the website. CSS was used to style the web pages, add colors, spacing, buttons, and cards. Navigation links were added to move between different sections of the website.

## 6. Testing and Results
The website was opened in a web browser to check its appearance and functionality. The navigation links and different sections were checked. Screenshots were captured to document the completed work.

## 7. Conclusion
Through this project, I learned how to create a basic static website using HTML and CSS. I also gained practical experience in writing code, organizing project files, styling web pages, and testing a website.
